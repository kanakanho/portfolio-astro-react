# Astro React Template

- Astro
  - Vite
  - React
- Biome
- Storybook

# Getting Started

## 開発用サーバーの起動
```sh
$ pnpm dev
```

## ビルド
```sh
$ pnpm build
```

## プレビュー
```sh
$ pnpm preview
```

## Linter & Formatter
```sh
$ pnpm biome
```

## Storybook
```sh
$ pnpm storybook
```

> [!WARNING]
> Storybook は React コンポーネントでのみ利用が可能です
